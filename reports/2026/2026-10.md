## 1. 本期核心判断

- 点目标检测 → 4D 成像 → 稠密空间理解 → AI 原生感知 → 网络化无线感知

- 60 / 77 GHz → 120 / 140 GHz → 220 / 300 GHz Sub-THz

本期（2026-09-07 ～ 2026-10-07）特别值得关注的信号包括：4D Radar 向 semantic segmentation、scene flow、occupancy 与 dynamic scene reconstruction 扩展；单芯片毫米波雷达开始尝试完整人体 Mesh 重构；多站雷达开始联合完成 tracking + identity continuity；ISAC 从论文和标准讨论推进到真实运营商网络试验。

## 6. 重点交叉方向

### 6.1 4D Imaging × 车载环境感知

2026 年 4D Radar 研究已经从传统 3D object detection 扩展到 semantic segmentation、motion estimation、occupancy prediction 和 dynamic scene reconstruction。

代表资源：
- Recent Advances in Millimeter-Wave 4-D Imaging Radars: A Leap Toward Massive MIMO in Sensing
- 4D Radar Perception Algorithms for Autonomous Driving
- K-Radar
- View-of-Delft

成熟度：E / T

主要难点：
- Radar tensor 数据量巨大
- 角分辨率仍低于 LiDAR
- multipath / ghost
- 数据集与硬件域差异
- 实时部署与功耗

未来 1–3 年：
- Object Detection → Dense Occupancy → Dynamic World Model
- 更强的跨传感器 / 跨硬件泛化
- 4D radar 与端到端自动驾驶感知融合

### 6.2 AI-native × 单芯片 Radar

ICCV 2025 Oral 的 Generalizable Radar Transformer（GRT）使用约 100 万 raw radar samples / 29 小时数据，直接从 4D radar cube 学习 occupancy、depth、semantic segmentation 与 ego-motion。

趋势：
ADC / IQ → Radar Cube → Tokenizer / Transformer → Multi-task

成熟度：F

主要难点：
- 缺少大规模统一 radar corpus
- 不同雷达阵列、带宽、chirp 配置带来的 domain shift
- 缺乏统一 radar token / interface

未来：
- Radar Encoder + Task Heads
- Self-supervised / masked radar pretraining
- Cross-device foundation representation

### 6.3 4D Radar Super-Resolution × 稠密感知

ICASSP 2026 的 MMSRFormer / mmSRFormer 以 Transformer 做稀疏毫米波点云超分辨；2026 IEEE RA-L 又出现基于 diffusion 的 radar point-cloud enhancement。

演进：
Interpolation → CNN → Transformer → Diffusion

成熟度：F → T

关键风险：
- 生成点是否有真实电磁回波支撑
- hallucination 与物理一致性
- 跨雷达泛化

未来：
- Physics-constrained Super-Resolution
- Uncertainty-aware enhancement
- Radar-native generative priors

### 6.4 AI × 3D人体姿态

2026 年主要路线包括：
- PoseGraphNet：图结构 + pose prior
- EMDUL：利用无标签毫米波与 LiDAR pose 数据
- Wave2Body：Radar Tokens → Body Tokens

数据集：
- MM-Fi：40 人、320k+ synchronized frames、5 modalities
- M4Human：进一步扩展到完整人体 Mesh

成熟度：F

难点：
- 雷达观测的是散射中心而不是人体表面
- 肢端信息弱
- self-occlusion
- cross-subject / cross-room 泛化

未来：
Direct Joint Regression → Body Representation Learning → Foundation Body Prior

### 6.5 AI × Human Mesh Reconstruction

成熟度：F / X  
本月变化：↑↑

难点：

- 稀疏点云

- self-occlusion

未来：

- Uncertainty-aware mesh
- Cross-modal teacher
- Temporal body prior
